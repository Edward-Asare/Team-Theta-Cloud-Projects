Static Website Hosting on AWS

This portfolio site is hosted on a private S3 bucket and delivered globally through CloudFront with HTTPS, ACM, and Route 53.

View Architecture

Architecture

  • Amazon S3 stores static files privately.
  • CloudFront serves the site through edge locations.
  • Origin Access Control prevents direct public S3 access.
  • ACM provides the TLS certificate for HTTPS.
  • Route 53 routes the custom domain to CloudFront.
